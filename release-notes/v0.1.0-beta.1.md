# FLEX v0.1.0 Beta 1

FLEX is a Windows desktop AI assistant that turns natural-language requests into validated tool actions, with local permission checks, confirmations for sensitive operations, and verification of reported results. OpenRouter provides the AI service; it is configured separately by each user.

## Features in this beta

- Desktop chat and a configurable edge overlay.
- OpenRouter-backed AI chat and registered Windows tools.
- Optional voice input with on-device Whisper transcription and Windows speech output.
- Optional Discord integration with per-user activation and confirmation safeguards.
- Browser automation using the bundled Playwright Chromium runtime.
- Local chat history, notes, tasks, research history, preferences, and automation state.
- Windows system controls, file search, and accessibility-focused utilities.

## Installation

1. Download `FLEX-Setup-0.1.0-beta.1.exe` and its `.sha256` file from the Assets section.
2. Verify the installer checksum if desired, then run the installer. Windows may show a SmartScreen warning because this beta is not code-signed.
3. Launch FLEX from the Start Menu. Add an OpenRouter API key in FLEX Settings to use AI features.
4. Configure optional Discord access in the Discord panel. Voice input downloads the `small.en` model on first use and needs a microphone and an internet connection for that initial download.

FLEX requires 64-bit Windows 10 or 11. The installer does not include credentials or personal application data. Settings and saved application data remain in the current Windows user profile and are not removed by uninstalling FLEX.

## Known limitations

- This is a beta build and has not been validated on every Windows device, audio driver, display, or account configuration.
- AI chat and live web/weather features need network access; AI chat also needs a valid OpenRouter key and may incur provider charges.
- Discord requires a bot token and configuration by the user.
- Voice recognition is CPU-based and its first-use model download is approximately 500 MB; recognition speed depends on the computer.
- Some system controls depend on Windows permissions and hardware support. Browser automation can be affected by websites, sign-in requirements, and network conditions.
- The installer is not Authenticode-signed, so Windows may display a publisher warning.
- The repository does not yet include a formal `LICENSE` file, so reuse and redistribution terms are not specified.

## Beta notice
